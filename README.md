# Portfólio - Felipe Terzi

Site pessoal de portfólio com apresentação, habilidades, lista de projetos,
galeria de desenhos e contatos.

## Site publicado
https://drfelas.github.io/portfolio-felipe-terzi/

## Tecnologias usadas
- HTML5
- CSS3 (variáveis CSS, flexbox e media queries para responsividade)
- Google Fonts (Fraunces e Inter)
- Git e GitHub (branches, Pull Requests)
- GitHub Pages (publicação)

## Estrutura
- `index.html`: página principal
- `css/style.css`: estilos do site
- `img/`: foto e desenhos
- `projetos/desenhos.html`: galeria de desenhos
